# Data

FraudLens uses the **Credit Card Fraud Detection** dataset from the Machine Learning Group of the
Université Libre de Bruxelles (ULB), published on Kaggle:
<https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud>.

- 284,807 card transactions made by European cardholders over two days in September 2013.
- 492 are fraudulent (about 0.172%).
- `V1`–`V28` are PCA components; the original features are confidential. `Time` is seconds since
  the first transaction in the file, `Amount` is the transaction amount, `Class` is 1 for fraud.

## How to obtain it

The file is **never committed** (`data/raw/` is git-ignored). Either:

1. Download `creditcard.csv` from the Kaggle page above (a free account is needed), or
2. Use the identical copy that TensorFlow hosts for its imbalanced-data tutorial:

   ```bash
   curl -L -o data/raw/creditcard.csv \
     https://storage.googleapis.com/download.tensorflow.org/data/creditcard.csv
   ```

The copy used for the committed reports came from option 2. Its contents were checked against the
published description (284,807 rows, 492 frauds, 31 columns) before use.

Place the file at `data/raw/creditcard.csv` and check its hash:

| File | Size (bytes) | SHA-256 |
|---|---|---|
| `data/raw/creditcard.csv` | 150,828,752 | `76274b691b16a6c49d3f159c883398e03ccd6d1ee12d9d8ee38f4b4b98551a89` |

```bash
sha256sum data/raw/creditcard.csv                             # Linux / macOS
Get-FileHash data/raw/creditcard.csv -Algorithm SHA256        # PowerShell
```

Training records the hash of the data it used in every artifact's `metadata.json`.

## Limits

- Only two days of data, from 2013, from one European issuer. Fraud patterns drift, so results do
  not transfer to other portfolios or to today.
- PCA features cannot be read as human concepts, so explanations name components such as `V14`.
- Labels come with the dataset. Real systems see labels late (chargebacks arrive weeks later),
  which this offline setup does not model.

## Synthetic fixture

`tests/fixtures/creditcard_sample.csv` is a 3,000-row **synthetic** file with the same schema,
generated by `tests/fixtures/make_fixture.py`. Tests and CI use it. It contains no real data.
