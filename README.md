# FraudLens

Fraud detection on a heavily imbalanced public card-transaction dataset (about 0.17% fraud), evaluated honestly: a time-based split, PR-AUC and recall at fixed precision with confidence intervals, a decision threshold chosen from an explicit cost model, explanations per transaction, and a tested FastAPI scoring service.

**Status:** planned. See the product requirements: [docs/prd/FL-01-fraudlens.md](docs/prd/FL-01-fraudlens.md).

Rebuilds the design of a Fall 2024 course project (CSC 450, Berea College) whose original code was not preserved.
